# Iron.io

> Iron.io provides hosted serverless infrastructure for background processing and asynchronous messaging. Its flagship products are IronMQ (a high-performance hosted message queue with pull and push queues, subscribers, and long-polling), IronWorker (a container-based, multi-language work-on-demand platform for background jobs and scheduled tasks), and IronCache (a hosted key/value store). All services share one REST/HTTP API authenticated with a per-project OAuth token from the Iron.io HUD.

## APIs

- [IronMQ v3](https://dev.iron.io/mq/3/): High-performance hosted message queue — post/reserve/delete messages, push queues, subscribers, webhook ingestion. Base: https://mq-aws-us-east-1-1.iron.io/3
- [IronWorker](https://dev.iron.io/worker/): Container-based worker platform — upload code, queue tasks, schedule jobs, pull logs/stats. Base: https://worker-aws-us-east-1.iron.io/2

## Authentication

- Per-project OAuth token in the Authorization header: `Authorization: OAuth <TOKEN>` (or `?oauth=<TOKEN>` query param). Token obtained from the HUD; shared across IronMQ, IronWorker, and IronCache. See authentication/ironio-authentication.yml
